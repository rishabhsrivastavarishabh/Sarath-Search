# 🤝 Contributing to Sarath Search Engine

Thank you for your interest in contributing to Sarath Search Engine!

## 🚀 Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/your-username/sarath-search.git
   ```
3. Create a feature branch:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. Install dependencies inside `frontend/`:
   ```bash
   cd frontend
   npm install
   ```

## 🛠️ Guidelines & Code Style

- **TypeScript**: Ensure strict type checking without `any` overrides where possible.
- **Linting & Formatting**: Run `npm run lint` and verify clean compilation.
- **Pull Requests**: Submit clean PRs with descriptive titles and reference associated issues.
